# Home Security & Automation Infrastructure

**Status:** Future / Planning

A future locally controlled home security and management system integrated with the homelab.

Potential components include Home Assistant, local IP/PoE cameras, Frigate NVR, MQTT, sensors, UPS monitoring, server/NAS monitoring, dashboards, and notifications.

The project prioritizes local processing and storage, open standards, and minimizing dependence on cloud subscriptions for core functionality.
