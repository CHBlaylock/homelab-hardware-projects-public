# OptiPlex 7060 Custom Enclosure

**Status:** Planning

A future project to reduce the footprint of a Dell OptiPlex 7060 SFF by replacing the original chassis with a custom enclosure.

The design will investigate retaining useful computing hardware while removing unused chassis volume associated with components such as an optical drive and conventional HDD bay.

## Design Goals

- Compact footprint
- Adequate airflow
- Serviceability
- Reusable/3D-printable components
- Compatibility with future homelab shelving or rack infrastructure
- Prototype and test before finalizing

Detailed measurements, CAD revisions, print settings, and thermal results will be added as the project progresses.

No final enclosure dimensions have been established.
