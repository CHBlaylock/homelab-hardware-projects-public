# Micro-ATX Custom Server

**Status:** Future / Planning

A future custom server project using reusable components left over from a gaming PC upgrade.

The project will begin with an inventory and compatibility assessment of the recovered hardware. The final workload and enclosure design will be determined from the available components rather than purchasing a server platform prematurely.

Planned documentation includes component selection, compatibility, power, cooling, storage, networking, enclosure design, testing, and lessons learned.
