# Compact Homelab Rack

**Status:** Planning

A temporary, modular homelab enclosure designed for a current living environment and future migration to a dedicated server/networking space.

The design emphasizes standardized dimensions, 3D-printed adapters, modular shelves, cable management, 2.5GbE networking with a path toward 10GbE, ventilation, UPS planning, and deliberate expansion capacity.

Standalone Raspberry Pi appliances are treated as independent devices rather than requiring dedicated rack positions.
